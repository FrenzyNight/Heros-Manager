# 유지보수 리팩터링

## 경계와 계약

Unity에 연결된 컴포넌트 이름, 직렬화 필드 및 GUID를 유지하면서 계산 규칙을 순수 C# 클래스로 옮겼습니다. 기존 외부 호출은 호환 진입점을 통해 동작합니다. 패키지 의존성은 추가하지 않았습니다.

| 영역 | 변경 | 방지하는 실패 |
| --- | --- | --- |
| 테이블 | DTO/직렬화/조회 카탈로그/참조 검증 분리 | 순회 순서·연속 번호 가정, 잘못된 그룹 참조 |
| 저장 | 깊은 복제와 저장 성공 후 스냅샷 교체 | 실패한 저장·새 게임이 현재 메모리를 먼저 변경 |
| 경제 | 비용을 합산하여 한 번 검증·차감 | 부분 차감, 중복 재료 미검사, 반복 환불, 오버플로 |
| 이벤트 | 결과 계산과 UI 적용 분리, 대기 큐의 일일 저장 | 이중 보상, 무료 비용 -1 sentinel 거부, 이벤트 풀 고갈, 이어하기 시 소비 이벤트 부활 |
| 날짜 | 실제 테이블 순서로 진행, 전환 중 입력 제한 | 마지막 날 범위 초과, 반복 콜백, 일시정지와 전환 충돌 |
| 모험·캠프 | 단계별 설정 갱신, 소유 리스너/Tween 정리 | 이전 단계 가격 유지, 첫날 출발 잠금, 중복 출발·귀환 |
| 미니게임 | 생성·참조·이동·보상 장부 공통화 | 프리팹 원본 변경, 다른 게임의 동일 이름 오브젝트 참조 |
| 미로 | 유한 DFS 생성 | 무한 생성 루프, 고립 통로 |
| 컷신 | 명확한 현재/다음 행과 효과 수명주기 | 마지막 행 누락, 타이핑 리치텍스트 잘림, 음향 지연 필드 혼동 |
| 렌더링 | MaterialPropertyBlock, TMP 필수 리소스 갱신 | 반복 material 인스턴스 생성, 구형 TMP 리소스 인식 오류 |

## 추가로 수정한 데이터 문제

- 빨래 데이터 `L1_JenTImeMin` 오타를 실제 DTO 필드 `L1_JenTimeMin`으로 수정했습니다. 실행 JSON과 GameDesign의 JSON/CSV 사본을 함께 수정했습니다.
- 영문 번역의 빈 값뿐 아니라 `-1` sentinel도 한국어로 대체합니다.
- 이벤트를 다시 열면 현재 재료 보유량으로 선택 버튼을 갱신합니다. 저장의 `hasEventSnapshot`으로 구형 초기 이벤트 큐와 새 저장의 소진된 큐를 구분합니다.
- TextMeshPro의 현재 패키지 필수 리소스를 동기화했습니다. 프로젝트 TMP 설정과 기존 GUID는 보존하고 리소스 버전 표기를 갱신했습니다.
- 후반 미니게임의 비활성 상위 계층을 패널 내부에서만 열고 종료 시 복구합니다. 요정 창고의 상자 3종과 관찰자 방향 오브젝트 12개는 기존 에셋·자식 오브젝트에 다시 연결했습니다.

## 검사

`tools/Validate-Unity.ps1 -Check Rules`는 데이터 카탈로그, 경제, 가중 선택, 미로 연결성/무순환, 미니게임 생성 소유권, 단회 보상, 이벤트 결과, 비연속 스테이지/날짜 진행을 검사합니다.

`Play`는 실제 씬에서 타이틀 → 인트로 → 인게임 → 타이틀 → 인게임, 빈/1개 이벤트 풀, 비용 부족·무료 선택·중복 클릭, 채집 보상, 채집 지역 10곳의 미니게임 시작/종료, 스테이지 변경 및 최종 스테이지 종료를 확인합니다. 미구현 세계수 지역은 제외합니다. 사용자 게임 저장을 덮어쓰지 않습니다. `Save` 검사는 별도 임시 폴더를 사용합니다.

2026-11-05, Unity 6000.4.7f1에서 다음 검증을 완료했습니다.

- Rules: 데이터·경제·이벤트·미로·미니게임 규칙 검사 통과.
- Save: 구형 JSON, 이벤트 큐, 깊은 복제, 손상 복구, 쓰기 실패 검사 통과.
- Project: 3개 스테이지/55개 미니게임 데이터 행 검사 및 빌드 씬의 스크립트 누락 검사 통과.
- Play: 위 씬 흐름과 10개 지역 검사 통과, 수집된 런타임 오류 0건. 이벤트 재오픈 비용 갱신과 소진 큐의 씬 재진입 복원도 확인했습니다.
- Build: Windows x64 빌드 성공. 실행 파일에서 타이틀 메뉴 입력과 이어하기 후 인게임/한글 UI 렌더링을 확인하고 종료했습니다. 해당 Player.log에서 오류·예외를 발견하지 않았습니다.
- `git diff --check` 통과. 로그와 실행 파일은 `HerosManager/Logs`, `HerosManager/Builds/Windows`에 생성됩니다.

## 남은 범위

- Stage2/3의 일부 시작/보상 함수, 부적 레벨업, 도감, 전용 엔딩은 미구현 콘텐츠로 남아 있습니다.
- 데이터 감사는 기존 콘텐츠 경고 14개를 보고합니다. 여정 제목 문자열 12개, 세계수 미니게임 데이터 연결 1개, 이벤트 설명 문자열 1개입니다. 임의의 기획/문구를 채우지는 않았습니다.
- 캠프 타이머와 당일 선택 패널까지 포함한 완전한 중간 상태 저장, 모든 미니게임의 실조작 및 장시간 밸런스 검수는 별도 작업입니다. 현재 저장은 다음 날 시작 시점의 체크포인트입니다.
- 외부 에셋의 deprecated API 경고 및 Windows 외 플랫폼 검증은 기존 이식 보고서의 제한을 따릅니다.
